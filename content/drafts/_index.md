# Content Drafts — manu2print

Drop all SM posts, Substack drafts, and blog article drafts here before publishing.

---

## File naming convention

```
YYYY-MM-DD_platform_topic-slug.md
```

Examples:
- `2026-05-01_linkedin_kdp-margin-rejections.md`
- `2026-05-03_substack_canva-export-failures.md`
- `2026-05-05_blog_why-kdp-rejects-your-pdf.md`
- `2026-05-07_facebook_12-rejections-story.md`

---

## Platforms

| Platform | Format | Length | Tags |
|----------|--------|--------|------|
| LinkedIn | Story or insight post | 150–400 words | 3–4 hashtags |
| Facebook | Conversational, punchy | 80–200 words | 2–3 or none |
| Instagram | Visual-first, short | 50–150 words | 4–5 hashtags |
| Substack | Long-form, personal | 400–1200 words | No hashtags — use topics |
| Blog | SEO + value | 600–1500 words | Add to blog.ts tags array |
